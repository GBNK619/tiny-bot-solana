A deterministic MACD-trend dip-buying bot for Solana DEX bars (bars-replay/v1): it buys dips while MACD(12, 26, 9) sits above its signal line and CCI(14) is deeply negative, then exits on take-profit (+8%), stop-loss (-20%) or the trend turning. Long only, no leverage, no randomness.
